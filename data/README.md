# Data

The datasets used in this project are not included in this repository because of GitHub file-size limitations.

The analysis was conducted using the original retail transaction dataset and a processed version prepared during the data-cleaning and transformation stage.

The data contains transactional information used to analyse:

- Revenue and order performance
- Customer behaviour and segmentation
- Product performance
- Geographic performance
- Monthly revenue trends

The raw and processed datasets are retained locally and are not publicly distributed with this repository.
